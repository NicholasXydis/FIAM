# WHAT THIS FILE IS
#
# The record of which model file and which runtime produced each piece of agent research.
# Weights are multi-gigabyte files we cannot commit, so they live in models/ on disk, never in
# the repo. "We used Qwen" is not reproducible; a SHA-256 hash is.
#
# None of this affects a submitted number. src/pipeline.py uses no models, and
# requirements.txt alone reproduces the book, CPU-only.
#
# Check a file:   Get-FileHash models/<file> -Algorithm SHA256     (Windows)
#                 shasum -a 256 models/<file>                      (macOS / Linux)
# The harness also hashes each file and keeps the result beside it as <file>.sha256.json.

  why these  The strongest open models that fit a 16 GB card whole at 4-bit, from two vendors,

             1.78-bit, and not Apache or MIT), Llama 3.x (old, same licence), DeepSeek-R1
             distills (long reasoning, weak tool use), gpt-oss (control tokens break grammars).


# ---------------------------------------------------------------------------------------
# RUNTIME
# Pinned, because a different build or cache type can give different output from identical weights.
# ---------------------------------------------------------------------------------------
  llama.cpp  build b11132, commit 633733d0a, Windows Vulkan binary, extracted to models/llama.cpp/
  download   https://github.com/ggml-org/llama.cpp/releases/download/b11132/llama-b11132-bin-win-vulkan-x64.zip
             32,126,438 bytes
  device     Vulkan0, AMD Radeon RX 9070 XT, 16 GB. Elsewhere set LLAMA_SERVER and LLAMA_DEVICE.
  flags      -c 65536 -np 1 --seed 42 --temp 0 --jinja -ctxcp 0 -cram 0
             --chat-template-kwargs '{"enable_thinking": false}'
             Qwen adds -fa on -ctk q8_0 -ctv q4_0; Gemma runs its cache at full precision.
  why        Hermes refuses a window under 64,000 tokens. Qwen at 64K needs 17.5 GB with a
             full-precision cache, over the ~15.3 GB free, so its keys are 8-bit and values 4-bit.
             Context checkpoints crash this build on Qwen3.8's hybrid attention, so they are off.
             Thinking is off, so the plan an agent writes is the plan we can read.
  measured   Qwen 64K q8_0/q4_0: 16.3 tokens/s, 15.1 GiB. Gemma 64K: 72.5 tokens/s, 14.7 GiB.
  runner     Hermes Agent v0.21.4 (2026.9.21, upstream 16fe260a), one-shot, stream-json events,
             tool search off, only the fiam MCP toolset. Each transcript records the version.
