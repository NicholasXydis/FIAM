# WHAT THIS FILE IS
#
# A record of exactly which model file produced which piece of research.
#
# Why it exists: the model weights are multi-gigabyte files we cannot commit to git, and are
# not ours to redistribute anyway. So they live on disk and never in the repo. Without this
# file, nothing would say WHICH version of a model produced a given result. "We used Qwen"
# is not reproducible. A SHA-256 hash is.
#
# What you need to know before touching it:
#   - None of this affects our submitted numbers. src/pipeline.py uses no models at all.
#     requirements.txt is the only setup file you need to reproduce the book.
#   - No hardware requirements. Any machine that can load the weights gets the same output.
#   - If you download one of these models, run `sha256sum models/<file>` and paste the result
#     over the matching <pending>. That is the whole job.
#
# A SHA-256 is a fingerprint of a file's contents. Two people with the same hash have
# byte-identical files, which is how a judge can verify they ran what we ran.
